## Display colours

- While the filter is active, colours on the screen are **not true to the original**. Pause or switch off Eventide for colour-critical work (photo / video editing, print proofing, design).
- Eventide restores the display ramps it found at start when it quits, when you sign out and on errors. If the screen should stay tinted after a hard crash or a forced kill, start and exit Eventide again, or sign out and in again.

## Extended gamma range

The value `GdiIcmGammaRange` changes a **system-wide** Windows setting for all users of the PC. It is only written after your explicit consent: the checkbox in the installer, or the button in the settings with a UAC prompt. Uninstalling removes it only if Eventide set it.
